🧩 Capacity Planning — Mobile UI Mocks

Responsive concepts for the three Capacity Planning views. Dense desktop grids collapse into vertical, card-first layouts optimized for a single thumb.

Shared mobile patterns across all three views
  • Filters collapse into a sticky toolbar with a single “Filters” sheet (bottom drawer) instead of an inline filter row.
  • View switch (Puzzle / Staff / Timeline) becomes a segmented control under the header.
  • Period navigation stays as a compact ‹ Today › strip; swipe left/right also moves sprints.
  • Wide grids become one-entity-per-card; the “other axis” (sprints / projects) scrolls horizontally inside each card as chips.
  • Color coding preserved: amber = under, green = healthy, red = over capacity.
