📱 Mobile UX Design Decisions

🔄 Matrix → Card List
The desktop matrix (projects × members × sprints) doesn't fit on mobile. Instead, we show a card-based project list for the current sprint, with drill-down to see the full timeline per project.
👆 Tap to Drill Down
Tap a project card → see all members and their allocations across sprints (horizontally scrollable). Tap a cell → bottom sheet to edit allocation.
📊 Bottom Navigation
4 tabs: Matrix (project list), Members (capacity overview), Dashboard (KPIs), More (settings, import, etc). Replaces the desktop sidebar.
⬆️ Bottom Sheet for Editing
All edit operations use a bottom sheet pattern (native mobile feel). Includes quick presets (10%, 20%, 50%) for fast thumb input and multi-sprint apply option.
🎯 One Sprint at a Time
The project list shows data for the current sprint (with left/right navigation). This keeps the view focused and avoids horizontal scrolling on the main screen.
🧩 Puzzle Me Works Great on Mobile
AI suggestions are presented as actionable cards with Accept/Dismiss buttons. Perfect for quick review on the go — accept suggestions with one tap.
Navigation Flow: Project List (Screen 1) → Tap project → Project Detail with timeline (Screen 2) → Tap cell → Edit bottom sheet (Screen 4)
Alternative: Members tab (Screen 3) → Tap member → See their projects across sprints → Tap to edit
